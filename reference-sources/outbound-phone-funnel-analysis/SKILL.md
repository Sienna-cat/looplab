# 外呼手机号漏斗维度分析与投放名单生产

把"一批手机号明文 + 各漏斗阶段命中标记"变成"哪些维度驱动转化 + 可落地的分层投放名单"。

## 何时使用

- 分析外呼漏斗（全量 → 接通 → 接通20秒 → 意向/ABM → 成交/出单）的影响维度
- 从手机号筛选高转化号段、产出黑白灰名单或 S/A/B/C/D 分层名单
- 评估号段"扩散/放量"（把规则应用到源数据之外的号段）是否安全

## 核心原则（已被多轮验证，优先遵守，避免重走弯路）

1. **维度价值看样本外，不看样本内 IV/方差**。样本内 IV 随细分必然上升、组内方差也含大量噪声——它们会把过拟合误判成"有信号"。唯一金标准是 **50/50 切分的样本外 lift**。
2. **可落地覆盖率是硬约束**。高基数维度（前5位 `seg5`、`city`×细维度）IV 常虚高，但要求"每组样本≥阈值"后**覆盖率崩塌**（大量号无法分级）。评价维度必须同时看 (IV, 达标组覆盖率)。
3. **目标决定维度**。意向(ABM)主要看**地域**（城市×运营商）；成交(出单)对**号段世代/放号时代**更敏感（同组合内放号时代组内离散：ABM≈0.19 vs 出单≈0.65）。不要用 ABM 的最优维度去套出单。
4. **号码维度有天花板**。2维「城市×运营商」通常已榨干意向信息（lift≈1.4–1.6）；再加维度是过拟合。**深度成交靠投放前碰模型**（引入号码之外的行为/人群标签），不要在号码维度堆精度。
5. **筛选用低维，扩散用稍高维**。给"已存在的号段"定级用 2维（最稳）；把规则"扩散"到源数据外的新号段时，叠加放号时代（3维）做**风险控制**——但这是假设，必须用真实成交回测，离线数据证不了。
6. **前7位号段 = 地市级 HLR**，唯一决定 省/市/运营商/放号时代；同一前7位号段内这些维度恒定。所以"号段层面"是天然的落地与扩散单位。
7. **跨业务不可迁移**。不同业务（号池来源不同、转化目标不同）的最优号段画像可能 0 重合且相反，互相验证不出来是正常的，别硬借鉴。

## 工作流

### 1. 数据准备与维度富集
- 输入：各漏斗阶段一份手机号明文文件（全量、接通、20秒、意向、成交）。以全量为底，给每个号打 `in_connect / in_talk20 / in_abm / in_order` 等命中标记。
- 富集维度（用 `phone` 库解析 + 字符串特征 + 外部映射）：`province, city, operator(_type), seg3/seg4/seg5(前3/4/5位), seg7(前7位), city_tier, 放号时代/发行年, region/cluster/econ_tier, 靓号等级` 等。
- 存为 `enriched.pkl`（pickle + category 类型，省内存）。维度清单与解析方法见 [reference.md](reference.md)。

### 2. 全漏斗维度交叉遍历（新逻辑）
运行 `scripts/cross_funnel.py`。对每个漏斗输出：单维全排名、两维全遍历、覆盖率约束下的前向选择、推荐可落地组合。
- **关键**：IV 只用达标组（cnt≥min_base）计算并**丢弃**不达标组，同时报真实覆盖率；前向选择带覆盖率约束；不要用"基数≤N"硬剔除任何维度（那会误杀 city）。

### 3. 样本外验证选维度
运行 `scripts/validate_oos.py`。对候选组合（2/3/4/5维）做 50/50 切分，train 定级、test 验真实 lift。**选样本外 lift 最高、衰减最小者**，通常是 2维。对成交目标另跑一遍（出单稀疏，多 seed 取均值）。

### 4. 生产分层名单（P0/P1/P2 双口径交叉验证）
运行 `scripts/tier_list.py`。
- 用两套口径各自定 S 级组合（如 2维城市×运营商 与 4维省份×发行年×城市等级×运营商），各取 topN 号段。
- **P0 = 两口径交集**（双重验证，分半检验证明 lift 最高、最稳）；P1/P2 = 各自独有。
- 放量时放开 topN 约束（交集上限=全 S 级交集），lift 温和下降、稳定性不降。

### 5. 落地
- 名单按 **P0 → P1 → P2** 排期。
- **筛选**（源数据已有号段）用 2维；**扩散**（生成源数据外号段）用 3维（+放号时代）。
- **枚举展开**：前7位号段 × `0000~9999` 生成 11 位号（`scripts/` 思路：固定后缀列表批量拼接写盘）。展开号大部分是空号/未放号——**投放前碰模型筛**，再小流量验证 lift 复现后放量。
- 人群画像（年龄/性别）用于**碰模型环节**，不要拿去做号段筛选（号段世代≠用户年龄）。

## 三大避坑（实战教训）

1. **可操作池别用"基数≤N"硬剔除** → 会把 city（基数~291）一刀切掉，导致最优组合"城市×运营商"永远选不出来。改用覆盖率约束自然筛。
2. **别拿样本内 IV / 组内方差当信号** → seg5 单维 IV 常最高但覆盖率仅个位数%（过拟合陷阱）；组内方差大也可能全是小样本噪声。一切以样本外为准。
3. **别用一个目标的结论套另一个目标** → ABM 用 2维封顶，但出单对放号时代敏感；扩散和筛选的最优维度也不同。

## 参考与脚本

- 计算公式（IV/覆盖率/Wilson/lift）、维度清单、ROI 口径：[reference.md](reference.md)
- `scripts/cross_funnel.py` — 全漏斗维度交叉遍历（执行）
