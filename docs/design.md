# LoopLab 营销评测工作台设计

目标：将已整理的两个 Skill 做成可运行、可讲述的产品 Demo，评测是主要任务。

范围：项目概览、客群泛化、智能核单、作品集说明四个页面。沿用现有营销闭环叙事。历史证据与模拟数据分别标识，不宣称已接入生产 Skill、地图、录音或营销投放。

技术：原生 HTML/CSS/ES modules，Node 20+ 内置静态服务器和测试工具；无第三方运行依赖。独立放在本目录，不修改其他项目。

交互：
- 客群页用稳定可复现的虚构客户数据，分训练、验证、测试集。用户配置二维/三维、样本下限、入选 lift；开发评测不访问测试标签。冻结后才计算测试指标，改变配置清除当前测试结果，重复使用测试集显示探索标记。
- 核单页使用虚构地址及独立标注。规则引擎只读取输入，评测层读取真值。比较基础规则与证据优先版本，输出原始值、候选、步骤、错误分类。人工裁决与模型预测分别保存。支持本地 CSV 导入，未标注数据不计算正确率。
- 导出结构化 JSON 结果，CSV 模板仅包含虚构记录。数据在本地浏览器处理，不提交外部服务。
- 作品集页解释边界、设计取舍、评测方法、历史结果、后续验证；支持打印。

视觉：深青色侧栏，灰白工作区，青绿主色，琥珀色风险强调；桌面信息密度适中，手机横向导航和纵向卡片。所有按钮都执行对应操作，表格支持键盘和小屏横向滚动。

验收：Node 核心逻辑测试；浏览器验证四个页面、两个工作流、CSV 导入、导出、人工记录、移动端布局与控制台。
