# 历史源码与汇总证据

这些文件用于说明作品集的历史方法和依据，不参与 LoopLab 网页运行。

- `address-check/`：地址校核 Skill、Python 脚本、规则参考和行政区划 JSON。未包含 ASR 模型权重、录音或个人缓存，未执行历史安装脚本。
- `address-history/`：历史迭代、Bad Case 机制及产品设计记录。
- `outbound-phone-funnel-analysis/`：历史人群分析方法和脚本。
- `audience-analysis/`：两份维度筛选/唯一标识复核脚本、它们引用的本地辅助模块及汇总报告。

历史脚本保留原配置语义与旧运行路径，未在本次重新执行；它们需要 Python、各脚本所列第三方依赖、另行配置的数据目录及合法授权的原始输入。当前仓库没有真实客户明细、手机号/MD5名单、录音链接、地图缓存或 API 密钥，不能仅凭此包重现历史业务指标。文中的历史结果是原报告记录。

可直接复现的是根目录的 Node 网页演示与测试。不要在 GitHub 上传原始业务数据或 `.env`。历史文本中形似完整手机号的字符串在交付副本中替换为 `[号码已脱敏]`；地方名称、汇总口径和算法保留。
