## 地址批次

来源：`地址校验工具pro/output/测试_1645.csv` 与同批 `优化分析汇总.csv`、`测试_1645_优化分析.csv`。

脚本逐行读取 UTF-8-SIG CSV，统计 `状态` 和 `备注`。结果与同批优化报告一致：

| 统计项 | 数值 |
| --- | ---: |
| 记录数 | 3,985 |
| 空状态 | 2,936 |
| 待人工 | 1,014 |
| 无效 | 35 |
| 含 `[已纠]` 的记录 | 39 |
| 可发货比例（空状态 ÷ 记录数） | 73.68% |
| 待人工比例 | 25.45% |
| 无效比例 | 0.88% |
| 已纠正标记比例 | 0.98% |

这里的“空状态”按同批优化报告的“可发货”解释。它是工具分流结果，不是人工确认后的地址准确率。`无效`是地址冲突状态，不等同于客户或订单无效。`[已纠]`表示发生纠正，不等同于纠正正确。

同批报告记载处理耗时 2.6 秒，参数为 `amap-scope=none`。该数值来自历史报告，不是本次重新测速；它不代表开启高德、录音重听和完整流程时的端到端耗时。

## 唯一客户标识策略复核

复核了 `维度`、`train_lift`、`test_lift`、`衰减%`、`test覆盖率%` 原值。唯一客户标识口径报告记录总行数 10,489,746，唯一 MD5 9,199,438，重复行 1,290,307，出单出现 MD5 4,216。

| 目标 | 策略 | train lift | test lift | 衰减 | test 覆盖率 |
| --- | --- | ---: | ---: | ---: | ---: |
| 全量→出单 | 归属地省 × 运营商 | 1.56 | 1.27 | -18.51% | 15.78% |
| 全量→出单 | 归属地省 × 运营商 × 号段世代 | 1.66 | 1.17 | -29.62% | 21.76% |

这些值来自历史样本外切分。因为历史流程用留出表现参与候选排序，所以它们适合说明方案比较和产品取舍，不应被包装为最终上线测试集结果。正式上线前需要冻结规则，再用时间外或新号段测试集进行一次最终验收。

## 口径风险

1. 地址模块的历史报告存在 3,985、3,998、5,047、5,320 等不同批次，不能拼成一个版本提升曲线。
2. 地址状态在不同版本中出现空、可发货、待抽查、待人工等表达，接入统一营销链路前需要状态映射表。
3. 泛化模块的“达标组覆盖率”与“入选客群覆盖率”是不同指标，不能互换。
4. 号码原始行口径与唯一客户标识口径的 lift 不同，统一看板必须固定分母。
