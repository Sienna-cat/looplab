# 参考：公式、维度、口径

## 关键指标公式

### IV（Information Value，含 Laplace 平滑 + 覆盖率约束）
对某维度组合分组，**只保留** `cnt ≥ min_base` 的达标组（丢弃不达标组，不要并入"其他"——并入会掩盖稀疏问题、虚高 IV）。

```
对每个达标组 i：
  good_i = 命中数 + 0.5 ; bad_i = (组内号数 - 命中数) + 0.5
  gd_i = good_i / Σgood ; bd_i = bad_i / Σbad
  IV  = Σ (gd_i - bd_i) * ln(gd_i / bd_i)
覆盖率 coverage = Σ(达标组号数) / 总号数
```
IV 判读：<0.02 无效，0.02–0.1 弱，0.1–0.3 中，>0.3 强。
**必须同时看 coverage**：高基数维度 IV 高但 coverage 低 = 过拟合，不可落地。

### Lift
`lift = 组转化率 / 整体转化率`。整体转化率 = 该漏斗入口内目标命中率。

### 加权离散度（衡量某维度区分力 / 组内异质性）
`wstd = sqrt( Σ w_i * (lift_i - 1)^2 )`，`w_i` = 组号数占比。组间用于"区分力"，组内（固定母组合再按子维度分）用于"异质性"。

### Wilson 95% 置信区间（稀疏目标如出单的稳健下/上界）
```
p = k/n ; z = 1.96
center = (p + z²/2n) / (1 + z²/n)
half   = z*sqrt(p(1-p)/n + z²/4n²) / (1 + z²/n)
下界 = center - half ; 上界 = center + half
```
出单极稀疏时用 Wilson 上/下界代替点估计来定级，避免被偶然高值误导。

### 样本外验证（防过拟合的金标准）
50/50 随机切分 → train 上按维度组合算 lift、定 S 级（lift≥阈值 且 base≥min_base）→ 在 test 上算这些 S 级组合的真实 lift。
- `train_lift`（样本内）通常随维度增多而升高；
- `test_lift`（样本外）才是真实泛化；`衰减 = test/train - 1`。
- 选 **test_lift 最高、衰减最小** 的口径。稀疏目标用多个 seed 取均值压噪声。

## 维度清单（手机号可解析）

| 类别 | 维度 | 说明 |
|---|---|---|
| 字符串特征 | seg3/seg4/seg5（前3/4/5位）、seg7（前7位）| seg7=地市级 HLR；seg5+ 高基数易过拟合 |
| 号码库解析 | province, city, operator, operator_type | operator_type 可细分虚商/物联网 |
| 放号属性 | 放号时代(band)、发行年(seg_launch_year) | 对成交比对意向更重要 |
| 地理派生 | region(大区)、cluster(城市群)、city_tier(城市等级)、econ_tier(经济档)、coastal/south_north | 多与 city 相关，注意冗余 |
| 号码属性 | 靓号等级(lucky_grade)、is_lucky | 对接通后深度沟通有微弱增量 |

注意：`city → province`、`city → city_tier` 强相关，city 单维常已涵盖三者大部分信息。

## ROI 口径（按需调整为项目实际数值）

```
成本 = 号数 * 数据成本 + 接通数 * 接通成本
收入 = 成交数 * 单均收入          # 或 ABM数 * ABM单价，取决于变现口径
ROI  = (收入 - 成本) / 成本
每号可回收利润 ppn = 转化率 * 单价 - (数据成本 + 接通率 * 接通成本)
```
分层/黑白名单可用 `ppn` 或 ROI 作为第二目标修正主轴（ABM lift）。

## 扩散的安全性自检（放量前）

1. **权重偏移**：S 级号段"号码量加权 lift" vs "号段等权 lift"差多少？差异小（如 <2%）说明等权展开不稀释。
2. **覆盖密度与质量是否相关**：按每号段样本量分档看 lift 是否一致；一致则展开安全。
3. **组内异质性**：母组合内按更细维度（放号时代）lift 是否分化——但务必用样本外区分"真信号 vs 噪声"。
4. **来源偏差**：源数据是随机号池还是历史触达回流？后者展开到纯净号会高估 lift。唯一解法是小流量 AB 验证。
